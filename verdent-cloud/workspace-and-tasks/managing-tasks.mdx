---
title: Managing Tasks
description: Create, switch, and continue Cloud tasks from the project workspace.
---

Tasks are the working threads where you ask Verdent to build, edit, debug, refactor, publish, or fix something. You can keep multiple tasks in a project and return to a previous task when you need its context.

<Steps>
  <Step title="Start a task">
    Open a project and describe the work you want Verdent to do.
  </Step>
  <Step title="Switch tasks">
    Use the task list or workspace navigation to move between active and historical tasks.
  </Step>
  <Step title="Continue the conversation">
    Reopen a task to preserve context, files, artifacts, and decisions from that session.
  </Step>
</Steps>

Use separate tasks when you want to compare approaches, keep a publish fix separate from feature work, or isolate a refactor from a content update.
