---
title: Differences from Desktop
description: Understand which Desktop concepts change or do not apply in Verdent Cloud.
---

Verdent Cloud shares the core agent workflow with Desktop, but several Desktop-specific concepts do not apply in the browser.

<AccordionGroup>
  <Accordion title="No local installation flow">
    Cloud runs in the browser, so Desktop installation, local system requirements, and local setup pages are not part of the Cloud tab.
  </Accordion>
  <Accordion title="No SSH remote project support">
    Cloud does not document SSH remote project workflows. Start from templates, Design Mode, or supported repository flows instead.
  </Accordion>
  <Accordion title="Cloud workspace instead of local workspace isolation">
    Cloud work happens in a Cloud workspace. Do not expect the same local folder isolation model as Desktop.
  </Accordion>
  <Accordion title="Preview is browser-based">
    Cloud preview uses browser preview surfaces and can be affected by browser embedding rules. Use preview address / preview URL wording rather than internal preview domains.
  </Accordion>
  <Accordion title="Need Manager? Use Verdent Desktop">
    Verdent Cloud is the lightweight, browser-based way to build. If you need Manager and its Desktop-specific capabilities, continue using Verdent Desktop — the two are complementary.
  </Accordion>
</AccordionGroup>
