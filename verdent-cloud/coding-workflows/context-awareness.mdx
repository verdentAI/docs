---
title: Context Awareness
description: Help Verdent use project files, conversation history, rules, and artifacts as task context.
---

Verdent Cloud uses the current project, workspace, task history, files, rules, and generated artifacts as context for future turns. Better context leads to better edits.

<Steps>
  <Step title="Keep related work in the same task">
    Continue the same conversation when the next prompt depends on previous decisions.
  </Step>
  <Step title="Point to relevant files or outputs">
    Mention the page, feature, artifact, or published app behavior you want Verdent to inspect.
  </Step>
  <Step title="Use project rules for persistent guidance">
    Store durable style, architecture, and workflow expectations in project rules.
  </Step>
</Steps>

When a task becomes too broad, split it into a new task with a clear summary of what should carry over.
