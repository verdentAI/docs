title: Channels
description: Connect Slack, Lark, or Telegram to work with Cloud Agents directly from your messaging apps
---

Channels connect messaging apps to Verdent Cloud, so you can start conversations and work with Cloud Agents directly from Slack, Lark, or Telegram without switching back to the Cloud interface.

Open **Channels** from the left sidebar. The navigation icon uses a radio or broadcast-style signal mark.

## Channel Actions

| Action | When it appears | What it means |
| ------ | --------------- | ------------- |
| **Connect** | The channel is not connected | Click Connect and follow the prompts to authorize. |
| **Switch** | The channel is already connected | Use Switch to change the connected target. |
| **Remove** | The channel is already connected | Use the trash icon to remove the connection. |

<Note>
The product UI currently shows Slack, Lark, and Telegram. This page does not document message types, webhook setup, permission scopes, bot commands, or API details.
</Note>
