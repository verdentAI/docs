---
title: Automations
description: Schedule recurring Cloud tasks for reports, checks, reviews, and maintenance.
---

Automations let you run recurring Verdent Cloud work without manually starting the same task every time.

<Steps>
  <Step title="Create an automation">
    Define the task name, prompt, schedule, timezone, and target project path.
  </Step>
  <Step title="Review execution history">
    Check previous automation runs to understand what happened and whether follow-up is needed.
  </Step>
  <Step title="Edit or disable when needed">
    Update the schedule or prompt as your workflow changes.
  </Step>
</Steps>

Good automation use cases include daily code review, weekly progress reports, health checks, and recurring cleanup tasks.
