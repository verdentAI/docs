---
title: MCP and Integrations
description: Connect external tools, services, and Cloud integrations to extend Verdent Cloud.
---

MCP and integrations let Verdent Cloud work with external services when your workspace is authorized to use them. Use integrations for tools that should be available across tasks.

<CardGroup cols={2}>
  <Card title="MCP tools">
    Connect supported tool servers so Verdent can call external capabilities during a task.
  </Card>
  <Card title="Cloud integrations">
    Use Cloud-supported integrations for repositories, services, and team workflows.
  </Card>
</CardGroup>

<Note>
  Cloud integration setup is account and workspace oriented. Local Desktop configuration paths should not be treated as the primary Cloud setup path.
</Note>
