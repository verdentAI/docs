---
title: Plan Workflows and Tuning
description: Tune planning, execution, and validation expectations for Cloud tasks.
---

Plan workflows help you decide how much structure Verdent should use before editing. Use more planning for high-risk work and less planning for small UI or copy changes.

<Steps>
  <Step title="Choose when to plan">
    Use planning for refactors, publish fixes, cross-file changes, or unclear requirements.
  </Step>
  <Step title="Set validation expectations">
    Tell Verdent what to run or inspect before it reports completion.
  </Step>
  <Step title="Iterate on the plan">
    Ask for changes to scope, order, or validation before implementation starts.
  </Step>
</Steps>


## Cost-aware workflows

Verdent Cloud shares the same credits and billing system as Verdent Deck. For routine work, use Eco Mode when available to keep working without spending credits, and reserve higher-cost model choices for complex reasoning or production-critical changes.
