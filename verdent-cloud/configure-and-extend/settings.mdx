Settings let you tune how Verdent behaves in a project or workspace. Use them for durable preferences that should apply across tasks, instead of repeating the same instructions in every prompt.

Keep settings concise. If a preference is temporary, put it in the task prompt instead of making it a project rule.


## Billing and credits

Verdent Cloud uses the same billing and credit system as Verdent Deck. Your credits are shared across Verdent products, so using Cloud does not create a separate Cloud-only credit pool or separate Cloud-only subscription.

## Eco Mode

Eco Mode helps you keep working without spending credits when your account has access to Eco Mode and compatible Eco models. When Eco Mode is on, Verdent Cloud uses an Eco-compatible model for supported tasks and can fall back automatically when the current model is not Eco-compatible.
