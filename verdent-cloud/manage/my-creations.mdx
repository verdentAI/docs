My Creations is the return path for your published apps. In the current Cloud experience, the default view focuses on apps you have already published. Generated websites, documents, data files, images, and files can also appear as creation cards when they are produced in a conversation.

## Supported creation types

<CardGroup cols={3}>
  <Card title="Websites">
    HTML and web outputs.
  </Card>
  <Card title="Documents">
    Markdown, PDF, Word, and presentation files.
  </Card>
  <Card title="Data and images">
    Spreadsheet files, images, ZIPs, and other generated files.
  </Card>
</CardGroup>

## Publish management

Deployment management lets you view the published URL, change visibility, update icon/title, unpublish a live app, and publish changes again. The URL slug is set during publishing and is not editable from the current management panel.

<Note>
  This page only documents the behavior supported by the current code evidence: published apps, creation cards, type parsing, opening creations, and published site fetching. It does not claim additional filters, sorting, recent-opened views, or URL slug editing after publish.
</Note>
