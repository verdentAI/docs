Templates are ready-made starting points for Verdent Cloud projects. Use one when you want to begin from a working app structure instead of asking Verdent to invent the product direction from scratch.

Starting from a template is the fastest creation path when the template is close to what you want to build. Verdent Cloud imports the template as a new project, then opens the editing workspace so you can customize the app with AI.

<Card title="Open Verdent Cloud" icon="cloud" href="https://cloud.verdent.ai/">
  Choose a template and create a new project in Verdent Cloud.
</Card>

## When to use a template

Use a template when:

- you want a working app foundation immediately
- the layout, app type, or use case is already close to your goal
- you prefer to customize existing pages instead of starting from a blank idea
- you want to skip Design Mode and move directly into editing

<Note>
Templates are different from Design Mode. A template gives you a concrete starting app. Design Mode helps choose a visual direction first when you only have a text brief or a rough product idea.
</Note>

## How to start from a template

<Note>
Using a template directly does not consume credits. You can start from a template for free, then decide how you want to customize the project.
</Note>

<Steps>
  <Step title="Open the creation flow">
    Go to Verdent Cloud and start creating a new project.
  </Step>
  <Step title="Choose a template">
    Browse the available templates and select the one that is closest to the app you want to build.
  </Step>
  <Step title="Create the project">
    Verdent Cloud imports the template and creates a project from that working starting point.
  </Step>
  <Step title="Customize with AI">
    After the project opens, use the editing workspace to change copy, layout, styling, behavior, data, or app structure.
  </Step>
  <Step title="Preview and publish">
    Review the app in Live Preview, continue iterating, then publish when it is ready.
  </Step>
</Steps>

## Template, Generate a Project, and Design Mode

The Generate a Project flow supports two practical creation paths: start from a template, or use Design Mode to turn an idea into an app.

<CardGroup cols={2}>
  <Card title="Use a template">
    Choose this path when you want to import a working app and adapt it to your needs.
  </Card>
  <Card title="Use Design Mode">
    Choose this path when you have an idea in words and want Verdent Cloud to help decide the visual direction before building.
  </Card>
</CardGroup>

If you already know the kind of app you want and a template is close, start from the template. If the visual direction is still unclear, use Design Mode first.
