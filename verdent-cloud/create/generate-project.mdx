## Design Mode

Design Mode is the project generation path for users who do not want to start from a template. Use it to turn an idea into an app — either by describing the app in the prompt box or by attaching an image/design as reference.

On the Cloud new task page, you can type an app idea directly. If no project is selected, Verdent creates a new project and sends your first instruction. If a project is selected, it sends the prompt into that workspace.

When you attach a design image or screenshot, Verdent uses it as visual context for the app you want to generate or modify.
